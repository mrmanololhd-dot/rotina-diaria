# Rotina DR

Dashboard de rotina diária (pomodoro, lembretes, kanban e metas), originalmente criado no Lovable.

- **O app** está na raiz (`index.html` + `assets/`) e é publicado pelo GitHub Pages.
- **Código-fonte** original fica em `codigo-fonte/`.
- Todos os dados ficam salvos no navegador (localStorage).
